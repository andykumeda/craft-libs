All four source branches were clean and pushed at the start of this rollout. Desktop Commander reported both devices offline, but direct SSH to the MacBook succeeded; no access handoff is needed at present. No installed app or user settings were modified by this inspection. Existing assistant preview signatures are ad hoc. Production assistant installation rejects ad hoc and Apple Development signatures: it requires a configured Developer ID publisher and Gatekeeper-approved package. Do not disable verification to bypass that contract. The customized branches must be reconciled with newer standard app releases before replacing those apps, and an authenticated assistant package must be prepared before deploying shared-helper app builds.

Upstream integration started: fetched PDFCraft v0.18.0, WordCraft v0.15.0 and GridCraft v0.16.0. Merge previews identify conflicts in app entry points, manifests and control/UI code; integration is being prepared separately before any installed bundle is replaced. SSH access to the MacBook remains available. Developer ID signing remains unresolved on both Macs.

The user chose a local-only signing approach on 2026-11-02. A disposable bundle signed by the Mini local certificate verified against its pinned certificate and identifier on both Mini and MacBook; a wrong certificate was rejected. Implementation, package installation, UI update source and full app deployment remain in progress. Public notarized releases retain their existing verification policy.
